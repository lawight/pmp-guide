M0 框架与五大过程组

五大过程组 🖼 🎵 A级默写

启动 → 规划 → 执行 → 监控 → 收尾
（立项）（定路线）（干活）（纠偏）（结算）

🎵 口诀："启规执监收"——启动立项、规划路线、执行干活、监控纠偏、收尾结算。

🧠 技巧：判断题问"第一步做什么"，先想是哪个过程组：没立项→启动；没计划→规划；干到一半→执行/监控；干完了→收尾。

项目 vs 项目集 vs 项目组合 📝

定义关键词
项目临时性努力创造独特可交付物临时+独特
项目集关联项目统一协调，获单独管理得不到的收益1+1>2
项目组合为战略目标集合项目/项目集/运营，按优先级排资源战略+优先级

组织影响：PM 权力连续谱 🖼

职能型 ─── 弱矩阵 ─── 平衡矩阵 ─── 强矩阵 ─── 项目型
PM权力小 ───────────────────────────────→ PM权力大

🧠 技巧：题目说"PM 权力小/资源在职能经理手里"→职能型；"PM 全权"→项目型。

PM / 职能经理 / 发起人 🧠

  • PM=对项目成败负责（日常）；职能经理=给资源（领域）；发起人=出钱+授权+章程。

EEF vs OPA 🎵

🎵 口诀："外 EEF 管不着，内 OPA 随便抄"——EEF 外部环境不可控（法规/文化/市场）；OPA 内部资产可复用（流程/模板/经验教训）。

章程 vs 计划 🧠

🧠 技巧：章程=授权证（能干什么），计划=施工图（怎么干）。授权问题永远先查章程。

M1 整合管理

变更管理流程五步 🖼 🎵 A级默写

①记录 → ②评估影响 → ③CCB审批 → ④批准/拒绝 → ⑤实施+更新基准

🎵 口诀："变更三连：记录→评估→审批"（后两步：批了才实施）。

🧠 技巧（最高频考点）：看到"范围/需求变化、干系人要求加功能"→先走变更流程；选项出现"直接做/直接拒绝/立即实现"=跳步，错。

变更请求 4 类 📝

纠正措施（纠偏差）/ 预防措施（防未来）/ 缺陷补救（修缺陷）/ 计划更新（改文档）。

🎵 助记："纠偏、防患、补漏、改文档"。

CCB 职责 🧠

批准/拒绝变更请求；不是所有变更都上 CCB——PM 权限内的小变更自己批。题目陷阱："任何变更都要 CCB"✗。

收尾三件事 🎵 A级默写

🎵 口诀："验收早做、经验教训、资产更新"（验收在收尾前已做完；收尾核心=经验教训+组织过程资产）。

🧠 技巧：收尾题选"收集经验教训/更新资产"，不选庆功会/最终风险审计。

项目收尾 vs 阶段收尾 🧠

🧠 技巧：阶段=中场检查（过了这阶段还有下阶段）；项目=终场结算（彻底结束）。

章程内容 📝 A级默写

目的/目标 · 高层级需求 · 可测量成功标准 · 总体预算与里程碑 · 发起人授权 · 关键干系人。

🎵 助记："目、需、标、钱、权、人"。

M2 范围管理

范围确认 vs 范围控制 🧠 🎵

🎵 口诀："确认验收对不对，控制变化怎么管"。

🧠 技巧：问"验收/签字"→确认；问"范围变了怎么办"→控制（走变更）。

蔓延 vs 镀金 🎵

🎵 口诀："蔓延是别人加，镀金是自己加"——蔓延=客户/干系人加需求不走流程；镀金=PM/团队主动加功能。都是错。

🧠 技巧：看到"客户要求加功能但没走流程"→蔓延；"团队主动多做"→镀金。

WBS 与 100% 规则 🧠

下层 = 上层的完全分解，不重不漏；最低层=工作包。

🧠 技巧：WBS 是范围工具（不是进度），按可交付物分解，不是按活动/部门。

范围说明书内容 📝

范围描述 · 验收标准 · 可交付物 · 除外责任 · 制约因素 · 假设条件。

🎵 助记："描验交除制假"。

滚动式规划 🧠

近详远粗，渐进明细（规划和 WBS 都适用）。

M3 进度管理

依赖类型 4 种 📝 A级默写

FS 完成→开始（最常见）· SS 开始→开始 · FF 完成→完成 · SF 开始→完成（罕见）。

🎵 助记："完开始（FS）最常见"；硬依赖=物理必然，软依赖=惯例，外部=项目外。

关键路径 CPM 🖼 🧠 D级计算

A(3) ──→ C(4) ──→ E(2)     路径 A-C-E = 9天 ← 关键路径（最长）
  ↘ B(2) ─→ D(5) ─→ E(2)   路径 B-D-E = 9天 ← 也关键（两条）

🧠 技巧：最长路径=最短工期；关键路径上浮动=0；多条关键路径=风险更高。先找最长，标出浮动 0 的链。

总浮动 vs 自由浮动 🎵

🎵 口诀："总浮动看项目（不误总工期），自由浮动看后活（不误后续最早开始）"。

正推/反推 🧠 D级计算

正推（从头）：ES=前序 EF 最大 +1（取最大）；反推（从尾）：LF=后序 LS 最小 −1（取最小）；浮动=LS−ES。

赶工 vs 快速跟进 🎵

🎵 口诀："赶工加钱（成本↑），跟进冒险（风险↑）"。

🧠 技巧：题目给"有预算"→赶工；"有并行空间"→快速跟进；都要先评估影响再选。

资源平衡 vs 平滑 🎵

🎵 口诀："平衡延工期，平滑不延"——平衡受资源硬约束（可能拖期）；平滑只在浮动内调（不拖期）。

PERT 三点估算 🎵 D级计算

🎵 口诀："(O+4M+P)÷6"；标准差=(P−O)÷6。

🧠 技巧：看到"最乐观/最可能/最悲观"→PERT；把三个数套公式。

应急储备 vs 管理储备 🎵

🎵 口诀："应急备已知（基准内），管理留未知（基准外）"——管理储备动用需批准。

M4 成本与 EVM

EVM 公式全表 🖼 🎵 A级默写 + D级计算

         计划价值 PV（按计划该干完多少）
实际成本 AC（花了多少）      挣值 EV（干完的活值多少）
SV = EV − PV（进度差）        SPI = EV / PV（进度比）
CV = EV − AC（成本差）        CPI = EV / AC（成本比）

🎵 口诀："EV 在上，好于 1 就好"——SPI/CPI 分子都是 EV；>1 超前/节约，<1 落后/超支。

🧠 技巧：SV/CV 是减法（正=好），SPI/CPI 是除法（>1=好）；题目给指标先判断是"差"还是"比"。

EAC/ETC/TCPI 🎵 D级计算

🎵 口诀："典型除 CPI，非典型加缺口"——

  • 典型（偏差继续）：EAC = BAC ÷ CPI
  • 非典型（偏差结束）：EAC = AC + (BAC − EV)
  • ETC = EAC − AC；TCPI = (BAC − EV) ÷ (BAC − AC)

估算方法 4 种 📝

类比（快粗）< 参数（统计模型）< 自下而上（最准最贵）< 三点 PERT（含不确定）。

🧠 技巧：问"最准确"→自下而上；问"最快"→类比。

成本基准 vs 管理储备 🎵

🎵 口诀："基准是尺子（绩效测量），管理储备是保险箱（未知风险）"。

M5 质量管理

质量 vs 等级 🎵

🎵 口诀："等级分高低，质量论好坏"——低等级≠低质量（经济舱服务好=低等级高质量）。

QA vs QC 🎵

🎵 口诀："QA 管过程（保证），QC 查结果（控制）"。

🧠 技巧：问"审计流程/确保按计划"→QA；问"检查交付物/发现缺陷"→QC。

预防 vs 检查 🎵

🎵 口诀："预防在前省，检查在后贵"。

7 大工具 🎵 C级应用

🎵 口诀："帕重、鱼因、控受、直布、散关、流步、核数"——

  • 帕累托=抓重点（80/20 优先解决）
  • 鱼骨图=找根因（RCA）
  • 控制图=看受控（连续 7 点同侧=失控）
  • 直方图=看分布 · 散点图=看相关 · 流程图=看步骤 · 核查表=收集数据

🧠 技巧：题问"缺陷集中在少数原因"→帕累托；"找根本原因"→鱼骨；"过程是否稳定"→控制图。

质量成本 CoQ 🎵

🎵 口诀："预防评估是一致，内外失败不一致"（一致性=预防+评估；非一致性=内部失败+外部失败）。

M6 风险管理

风险管理流程 🖼 🎵 A级默写

识别 → 定性 → 定量 → 规划应对 → 实施应对 → 监控

🎵 口诀："识定定应实监"（识别、定性、定量、应对、实施、监控）。

🧠 技巧：识别后先记风险登记册；"直接实施应对/直接上报"=跳步，错。

应对策略 🎵 A级默写

威胁：规避（消除）/ 转移（保险/外包）/ 减轻（降概率影响）/ 接受。

机会：开拓（确保）/ 提高（加大）/ 分享（合作）/ 接受。

🎵 口诀："威胁规转移减受，机会开提分接"。

🧠 技巧：题给"买保险/外包"→转移；"取消风险活动"→规避；"预留预算"→接受。

定性 vs 定量 🧠

定性=概率×影响矩阵排序（快、主观）；定量=EMV/蒙特卡洛数值（慢、客观）。问"优先级"→定性；问"数值/概率分布"→定量。

EMV 决策树 🧠 D级计算

EMV = 概率 × 影响；决策树逐分支算期望值，取收益最大/损失最小的分支。

风险 vs 问题 🎵

🎵 口诀："风险未来事，问题已发生"——已发生走问题/变更，未发生走风险管理。

残余 vs 次生 🎵

🎵 口诀："残余剩的，次生新长的"（应对后残留=残余；应对带来的新风险=次生）。

M7 采购与合同

合同类型 5 种 🖼 🎵 A级默写

合同全称风险承担
FFP固定总价卖方担成本风险
FPIF总价+激励卖方（有激励空间）
CPFF成本+固定费买方担
CPIF成本+激励买方
T&M工料混合（短工期/范围不清用）

🎵 口诀："固定总价卖方担，成本补偿买方担，工料混合两头沾"。

🧠 技巧：题目问"哪个风险最小给卖方/范围清楚"→FFP；"范围不确定"→T&M。

采购流程 📝 A级默写

规划采购 → 实施采购（询价/评标/签约）→ 控制采购（管理/索赔）→ 结束采购。

索赔 vs 争议 🧠

索赔=按合同提权利主张（先查合同条款）；争议=索赔谈不拢升级。采购出问题先查合同，不直接换供应商。

M8 资源与团队

团队五阶段 🖼 🎵 A级默写

组建 → 风暴 → 规范 → 成熟 → 解散
（客气）（冲突）（磨合）（高效）（散伙）

🎵 口诀："建风规熟散"。

🧠 技巧：题说"团队刚成立/彼此客气"→组建；"激烈冲突/争论"→风暴；"已高效自转"→成熟。

冲突五法 🎵 A级默写 + C级应用

撤退（回避）/ 缓和（求同）/ 妥协（各让一步）/ 强迫（赢输）/ 合作（双赢，最优）。

🎵 口诀："退缓妥强合，合作最优先"。

🧠 技巧：PMI 偏好=先私下沟通再正式，目标=合作双赢；直接替团队决定/强制=错。

仆人式领导 🧠 C级应用

移除障碍 · 授权赋能 · 教练辅导 · 服务团队。题给"团队求助/障碍/士气低"→仆人式领导（不微管理、不责备）。

激励理论 📝

马斯洛=需求层次（生理→安全→社交→尊重→自我实现）；赫茨伯格=保健（不满源）+激励（满意源）；麦克利兰=成就/权力/亲和。

RAM/RACI 🧠

R=干活（执行）、A=问责（唯一背锅）、C=咨询、I=知情。问"谁负责这项工作"→R；"谁最终负责"→A。

权力类型 5 种 📝 A级默写

正式（职位）/ 奖励 / 专家 / 参照（个人魅力）/ 惩罚。

M9 沟通与干系人

沟通渠道公式 🧠 D级计算

n(n−1) ÷ 2（n=人数）。

🧠 技巧：5 人=10，6 人=15，7 人=21——加 1 人就加 n 条。先算人数，套公式。

沟通方式 🎵

🎵 口诀："交互双向最有效（会议），推发拉取是单向"（推式=邮件/报告发出去；拉式=知识库/门户自己取）。

权力/利益方格 🖼 C级应用

           权力高
   令其满意 │ 重点管理      ← 权力高利益高 = 重点管理
───────────┼───────────
   监督     │ 随时告知      ← 权力低利益高 = 随时告知
           权力低
   利益低   │  利益高

🎵 口诀："高高重管，高利低满，低高告知，低低监督"（高权高利=重点管理；高权低利=令其满意；低权高利=随时告知；低权低利=监督）。

干系人参与度矩阵 🖼 🎵 A级默写

不知晓 → 抵制 → 中立 → 支持 → 引导
（完全不知道）（反对）（不表态）（配合）（主动推动）

🎵 口诀："不知抵制中立支持引导"；目标=把差距推向"支持/引导"。

期望管理 🧠 C级应用

先沟通后行动；管理期望≠承诺做不到。干系人反对→先私下会面了解关切（摸底 P9）。

M10 敏捷与混合

Scrum 三角色 🎵 A级默写

🎵 口诀："PO 管价值，SM 护流程，团队自交付"——PO 定优先级；SM 移除障碍/仆人式；开发团队自组织。

Scrum 四事件 🖼 🎵 A级默写 + C级应用

Sprint 规划（定目标选任务）→ 每日站会（15min 同步）→ 评审（看产品）→ 回顾（改过程）→ 下一轮

🎵 口诀："规站评回"；"评审看产品，回顾改过程"（摸底 A2 就是它）。

🧠 技巧：题问"展示增量"→评审；"改进协作/过程"→回顾；"15 分钟同步"→站会。

Scrum 三工件 🎵 A级默写

🎵 口诀："PO 管产品池（Backlog），团队领冲刺池（Sprint Backlog），增量按 DoD 交付"。

Sprint 内不中途加需求 🧠 C级应用

新需求进产品 Backlog，下个 Sprint 排期（摸底 A1）。"立即做/延长 Sprint"都错。

看板 🧠 C级应用

WIP 限制暴露瓶颈、提升流动效率；拉动式、连续流。题问"WIP 目的"→暴露瓶颈不是减量/禁并行。

看板 vs Scrum 🖼

Scrum看板
迭代固定 Sprint连续流
角色三角色无强制角色
工件三工件看板/泳道
变更Sprint 内不接新需求随时可加（WIP 内）

混合方法 🧠 C级应用

稳定部分用预测，不稳定部分用迭代（摸底 A4）；"先预测后敏捷"=Agile-fall 反面教材。

迭代 vs 增量 🎵

🎵 口诀："迭代反复磨，增量每段加"。

DoD vs DoR 🧠

DoD=完成的定义（增量达标线）；DoR=开始的定义（就绪线）。

故事点/计划扑克 🧠

相对估算（不是小时）；团队一起出牌、讨论达成共识。

敏捷宣言 4 价值观 📝 A级默写

个体互动 > 流程工具 · 可用软件 > 详实文档 · 客户合作 > 合同谈判 · 响应变化 > 遵循计划。

🎵 助记："人、软、客、变"。

用户故事 🧠

As a（角色）… I want（需求）… so that（价值）…；INVEST=独立/可协商/有价值/可估算/小/可测试。

M11 业务环境与合规

法规/合规影响 🧠 C级应用

外部法规变化→先评估合规影响，必要时走变更流程（摸底 B1）；"暂停项目/继续原计划"都错。

战略对齐 🧠

项目支撑组织战略；组合管理按战略优先级排资源。

🎯 考点清单 · 等级与考核

PMP 考点清单（12 模块全量 · 含掌握等级与考核要求 · 2026-08-15）

用途：抽背、出题、模块测试、考前复盘的考点总表。

掌握等级（A/B/C/D）：每个考点按认知要求分级，达到对应等级才算掌握，见下方定义。

豁免规则（2026-08-15）：标 ✂️ 不看 的考点完全不需要看——低概率（★）且对通过率影响 <1%，不学习、不抽背、不出题、不计入模块达标判定。其余考点按等级要求掌握。时间充裕想加回时取消标记即可。

掌握等级与考核要求

等级名称掌握要求考核方式达标线
A默写级能一字不差写出：公式 / 流程顺序 / 清单 / 名称dsh 随机抽 3 条默写（口头或纸上），错了现场补默全对
B辨析级能说清易混概念的区别，并各举一个应用场景dsh 给一对概念，你对比讲解通过（讲不出=未达标）
C应用级情境题能按 PMI 思维做对决策（第一步做什么）模块测试情境题 + 每日抽背情境题模块阈值（70~90%）
D计算级能正确计算并判读结果含义计算题一组 5 题，限时5/5 或 ≥90%

模块达标 = 该模块所有考点达到各自等级要求（✂️ 不看考点除外）+ 错题 100% 闭环。A/B 级靠抽背默写复检（1/3/7 天），C 级靠刷题正确率，D 级靠计算全对。
